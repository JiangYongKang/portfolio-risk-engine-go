# 设计与口径说明

本文档说明风险指标口径、数值处理方式、并发与更新规则、脏数据处理与验证方法。

## 1. 持仓净额口径

- 每条持仓带方向：`SideLong`（多）记 `+qty`，`SideShort`（空）记 `-qty`。
- 同一标的跨**所有账户**直接求和得到净数量 `NetQty`（多正空负）；
  同一账户同一标的**同时**存在多头与空头记录是合法输入，按统一口径抵消；
  只有 `(account, symbol, side)` 完全相同的重复行才算脏数据并拒绝。
- 合约乘数 `Multiplier` 与计价币种 `Currency` 只取自标的主数据，
  持仓记录本身不携带乘数/币种，杜绝同一标的多口径混用。
- 聚合结果按标的代码排序输出；币种、乘数、方向三者中任何一个无法确认时
  整批拒绝，绝不静默丢弃记录。
- 净额为 0 的标的保留在敞口列表中，但在风险计算阶段视为无敞口；
  所有标的净额均为 0（或无持仓）时返回 `EmptyPortfolio` 错误。

## 2. 风险指标口径

### 2.1 情景损益

对标的 j，单情景 t 的损益（币种单位）：

```
pnl_j(t) = NetQty_j * Multiplier_j * Price_j * r_j(t)
```

- `r_j(t)` 为简单收益率 `P_t/P_{t-1} - 1`（由历史情景直接给出）；
- `Price_j` 取该标的当前最新一条**有效**行情（时间戳最大者）；
- 空头因 `NetQty < 0` 自动得到相反符号，无需特判；
- 组合单情景损益为同币种各标的之和。**不同币种绝不混算**，输出按币种分组，
  组内按标的代码排序，保证结果稳定可复现。

### 2.2 历史模拟法

- 损失序列 `L(t) = -pnl(t)`（损失为正）。
- **VaR_c** = 损失序列的经验 c 分位数，采用线性插值
  （与 numpy `quantile` 默认 `'linear'` 口径一致）：
  `h = c*(T-1)`，`VaR = L_(floor h) + (h-floor h)*(L_(floor h+1)-L_(floor h))`。
- **ES_c**（期望尾部损失）= 损失不低于 VaR 阈值（含一个 1e-12 相对容差，
  吸收浮点抖动）的所有情景的算术平均；当没有任何情景严格落在尾部时，
  ES 等于 VaR（至少包含分位数所在的临界点，不会出现"无样本"空洞）。
- 观测数 `ObservationN = T` 随结果输出，便于审计样本充分性。

### 2.3 参数法（方差-协方差法）

- 波动率：各标的最近窗口（`VolWindow`，0 表示全部）的**样本标准差**
  （除以 N-1）。
- 组合损益方差：`σ_p² = wᵀ (diag(σ)·C·diag(σ)) w`，
  其中 `w_j = NetQty_j * Multiplier_j * Price_j` 为带方向的名义金额。
- **VaR_c = z_c · σ_p**，`z_c = Φ⁻¹(c)` 用 Acklam 有理逼近
  （全定义域相对误差约 1e-9；c≤0 给 -Inf、c≥1 给 +Inf）。
- 相关性矩阵可按任意标的顺序提供（`CorrSymbols`），计算时按币种组内
  标的顺序重排；矩阵未覆盖某个币种组时，**该组跳过参数法**，
  历史法仍正常输出。
- 参数法需要至少 2 个情景点估计样本标准差；只有 1 个点时波动率视为 0。

## 3. 数值处理（病态相关性防线）

对相关性矩阵 C 依次执行：

1. **结构校验**：方阵、维度与 `CorrSymbols` 一致；
2. **取值校验**：所有元素有限（非 NaN/Inf）且在 [-1-ε, 1+ε]；
3. **对角校验**：对角元素必须为 1（容差 1e-10）；
4. **对称校验**：`|C_ij - C_ji| ≤ 1e-10`；
5. **正定判定**：无主元 Cholesky 分解，半正定/奇异/非正定一律拒绝；
6. **条件数**：Higham 1-范数估计器（最多 5 轮，每轮两次三角回代，
   不显式求逆），估计 `cond₁ = ‖C‖₁·‖C⁻¹‖₁`。

判定阈值：

| 条件数估计 | 行为 |
|---|---|
| Cholesky 失败（奇异/非正定） | `CorrelationSingular` 错误，cond 记 +Inf |
| `cond₁ > 1e8`（`IllConditionedThreshold`） | `CorrelationSingular` 错误，**拒绝计算**，不静默放大误差 |
| `1e6 ≤ cond₁ ≤ 1e8` | 正常输出，`CondWarn=true` 标记可信度下降 |
| `cond₁ < 1e6` | 正常输出 |

**任何代码路径都不会输出 NaN 作为条件数**；奇异时统一记为 +Inf。
方差投影后若出现非有限值或显著为负（<-1e-10），同样拒绝；
-1e-10 以内的负噪声被夹到 0（浮点舍入补偿）。

## 4. 并发与更新规则

### 4.1 一致性

- 所有状态变更在写锁下完成；`Calculate` 在读锁下**深拷贝**出一致快照
  （持仓切片、标的映射、行情/情景存储全部复制），计算在锁外进行。
- 因此一次风险计算要么看到更新前的全部数据，要么看到更新后的全部数据，
  不会看到半批更新；快照与引擎后续写入完全隔离。

### 4.2 增量更新（`engine.Update`）

- 每批带单调序号 `Seq`（`Seq<=0` 表示不启用序号门控）：
  - **同 `Seq` + 完全相同内容**（FNV-1a 稳定指纹）：幂等忽略，可安全重试；
  - **同 `Seq` + 不同内容**：`DuplicateRecord` 拒绝；
  - **`Seq` 小于已应用序号**：`StaleUpdate` 拒绝，迟到数据不覆盖新数据；
  - 更大序号正常推进。
- 一批更新中**任何一条**非法（未知标的、坏价、NaN/Inf 收益率等），
  整批拒绝：先在存储的克隆上暂存全部变更，全部成功后才替换线上状态。
- **行情**按 `(symbol, time)` 幂等覆盖；重复应用同一条行情结果不变。
  同一装载批次内的 `(symbol, time)` 重复行直接拒绝。
- **情景**按时间戳唯一标识：
  - 允许**乱序到达**，内部按时间戳排序，投影时严格升序输出；
  - 同时间戳内容一致的重复提交幂等忽略；内容冲突则 `DuplicateRecord`；
  - 全量装载路径要求时间戳严格升序、非零。
- 情景只保证"存储合法"，与组合对齐在计算时完成：任一情景点缺少组合
  所需的任一标的收益率 -> `ScenarioLengthMismatch`。

## 5. 错误类型（失败原因可按类型区分）

`fault.ErrorKind` 枚举，配套构造函数；用 `fault.KindOf(err)` /
`fault.IsKind(err, kind)` 判定，或用标准 `errors.As` 解包
（错误被 `%w` 包装后类型信息仍保留）。

| Kind | 触发场景 |
|---|---|
| `UnknownInstrument` | 持仓/行情/情景引用了未注册标的 |
| `InvalidInstrument` | 空代码、乘数非正/非有限 |
| `InvalidPosition` | 空账户/标的、非法方向、数量非正/非有限、零时间戳 |
| `DuplicateRecord` | 同键重复持仓、同批重复行情、同时间戳冲突情景、同 Seq 冲突批次 |
| `MissingCurrency` | 标的未配置计价币种 |
| `QuoteMissingPrice` | 行情价格缺失、非正或非有限；计算时找不到有效最新价 |
| `ScenarioLengthMismatch` | 情景相对组合所需标的缺项（长度不齐） |
| `ScenarioOutOfOrder` | 全量装载情景时间戳非严格升序/为零 |
| `ScenarioBadValue` | 收益率含 NaN/Inf，或组合损益非有限 |
| `CorrelationSingular` | 矩阵非正定/奇异，或 cond₁ 超过 1e8 |
| `CorrelationShape` | 非方阵、维度不匹配、不对称、元素越界、符号数不符 |
| `InsufficientData` | 没有任何情景点 |
| `EmptyPortfolio` | 没有任何非零净敞口 |
| `StaleUpdate` | 增量批次序号过期 |

## 6. 验证方法

```bash
go test ./... -race        # 单元测试 + 竞态检测
go test ./... -count=1     # 关闭缓存，强制重跑
go vet ./...
go run ./cmd/riskdemo      # 端到端冒烟
```

测试覆盖（每个测试用例均通过 `log` 打印关键输入与判定依据）：

- **持仓**：多账户净额、同账户多空抵消、乘数/币种/方向、零净额、
  未知标的、非法方向/数量、空账户、重复记录、主数据校验；
- **行情/情景**：最新价选取、未知标的、0/负/NaN/Inf 价格、同批重复、
  幂等覆盖、乱序到达排序、重复提交不双计、同时间戳冲突、长度不齐、
  非有限收益率、空情景、快照深拷贝隔离；
- **统计**：分位数线性插值与不可变输入、正态反函数精度与尾部、
  样本标准差；
- **矩阵**：单位阵/普通相关阵的条件数（手算值对比）、完全相关奇异阵
  （cond=+Inf 且无 NaN）、高度相关病态阵（cond≈2e10 被拒）、
  形状/对称/对角/越界、负特征值路径无 NaN；
- **风险**：手算 VaR/ES（4 情景可枚举）、空头方向与乘数、多币种分组、
  可复现性（重复计算位级一致）、空组合/全对冲/缺价、参数法手算校验、
  相关阵顺序重排一致性、病态/奇异矩阵拒绝、非法置信度回退 0.99；
- **引擎**：端到端、同 Seq 幂等/冲突、过期 Seq 拒绝且不泄漏、
  混合脏数据整批原子拒绝、快照与后续更新隔离、
  200 次并发更新 + 多读者的竞态测试（`-race`）、计算结果无 NaN/Inf、
  并发后两次计算结果一致。
